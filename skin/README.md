# DS Viewer skin

The viewer looks up each picture by name here (also in a `skin` folder beside the installed program, or in your settings folder, which win over these).

| File | Used for |
| --- | --- |
| `background.png` | Login wallpaper (upload your own) |
| `loading-runner.gif` | Animation on the loading and teleport screens; a green background is keyed out (upload your own) |
| `login-crest.png` | Crest above the login card (upload your own) |
| `*.ico` + same-name `.png` | App, taskbar, shortcut and installer icon (upload your own) |
| `login-frame.svg`, `login-button.png` | Login card frame and LOG IN face |
| `button-gold.png`, `button-red.png` | OK / Apply / Reset and Cancel faces |
| `ball-1.png` … `ball-7.png` | Emblems: blossom, water, flame, sun, butterfly, wisteria, lightning |
| `slider-thumb.png` | Every slider's knob |
| `wordmark.png` | Large DS Viewer logo on the login screen |
| `wisteria.png`, `cloud-scroll.png`, `gold-flare.png`, `gold-dragon.png` | Ornaments (wisteria, gold waves, petal flame, katana) |
| `record-button.png`, `record-button-active.png` | Recorder RECORD / STOP |
| `icons/ds-*.png` | Gold interface icons |
| `toolbar/` | Toolbar faces, avatar frame, badges and `layout.json` (emblem and label per button) |
| `messenger/`, `notifications/` | Messenger and notification art |
